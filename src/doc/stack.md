# Стек технологий

Платформа Veda построена на открытых технологиях и стандартах. Ниже описаны основные компоненты.

---

## Серверная часть

Серверные модули платформы написаны на языке **[Rust](https://www.rust-lang.org/)** — это обеспечивает высокую производительность, надёжность и эффективное использование памяти.

### Хранение данных

| Компонент | Назначение |
|---|---|
| **[Tarantool](https://tarantool.io)** | Основное хранилище мастер-данных. Высокопроизводительная NoSQL СУБД с хранением в памяти и персистентностью на диск. |
| **[Xapian](https://xapian.org)** | Движок полнотекстового поиска. Используется для индексации и выполнения поисковых запросов по содержимому объектов. |
| **[ClickHouse](https://clickhouse.com)** | Опциональный компонент. Колоночная СУБД для хранения индексов и аналитических запросов по большим объёмам данных. |
| **[Oxygraph](https://oxigraph.org)** | Опциональный компонент. RDF-граф с поддержкой SPARQL. Используется для индексации онтологий и выполнения семантических запросов. |

### Исполнение скриптов

Серверная автоматизация реализована на **JavaScript**, исполняемом встроенным движком **[V8](https://v8.dev/)** (тот же движок, что используется в Node.js и Chrome). Скрипты запускаются в ответ на события изменения данных и используют полный доступ к API платформы.

---

## Клиентская часть

Веб-клиент реализован на **ванильном JavaScript** без дополнительных фреймворков. Интерфейс строится на основе **[Web Components](https://developer.mozilla.org/en-US/docs/Web/API/Web_components)** (Custom Elements v1) — стандарте браузера для создания переиспользуемых компонентов.

### Взаимодействие с сервером

| Протокол | Использование |
|---|---|
| **HTTP REST API** | Основной канал: чтение и запись объектов, поиск, управление правами. |
| **WebSocket** | Push-уведомления об изменениях в данных в режиме реального времени (CCUS). |

---

## Модель данных

Платформа использует методологию **[Semantic Web](https://www.w3.org/standards/semanticweb/)**:

| Стандарт | Использование |
|---|---|
| **[RDF](https://www.w3.org/RDF/)** / **[RDFS](https://www.w3.org/TR/rdf-schema/)** | Базовая модель данных: всё в системе — тройки «субъект — предикат — объект». |
| **[OWL](https://www.w3.org/OWL/)** | Описание онтологий: классы, свойства, ограничения. |
| **[Turtle (.ttl)](https://www.w3.org/TR/turtle/)** | Формат файлов онтологий. |
| **[RDFa](https://www.w3.org/TR/rdfa-primer/)** | Разметка HTML-шаблонов: связь DOM-элементов с данными онтологии. |
| **[SPARQL](https://www.w3.org/TR/sparql11-query/)** | Язык запросов к RDF-графу (поддерживается опциональным модулем Oxygraph). |

| Компонент | Описание |
|---|---|
| **Linux** | Основная платформа. Поддерживаются дистрибутивы на базе Debian/Ubuntu и RHEL/Rocky. |
| **AppImage** | Автономный образ приложения для быстрого старта в Linux без установки зависимостей. |
